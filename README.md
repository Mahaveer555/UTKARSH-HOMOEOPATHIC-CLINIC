## 🚀 Local Development

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Mahaveer555/UTKARSH-HOMOEOPATHIC-CLINIC.git
   cd UTKARSH-HOMOEOPATHIC-CLINIC
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open in your browser:
   ```
   http://localhost:3000/
   ```
